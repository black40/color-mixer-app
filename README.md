# 🎨 Color Mixer App

Простое десктопное приложение на Python с использованием Kivy и KivyMD, позволяющее выбирать цвет с помощью RGB-слайдеров и копировать его HEX-код.

## 🛠️ Возможности

- Регулировка значений Red, Green, Blue слайдерами.
- Превью цвета в реальном времени.
- Отображение HEX-кода выбранного цвета.
- Копирование HEX-кода в буфер обмена.

## 📦 Стек технологий

- [Python 3.12](https://www.python.org/)
- [Kivy](https://kivy.org/) >=2.3.1,<3.0.0
- [KivyMD](https://kivymd.readthedocs.io/) >=1.2.0,<2.0.0
- [Poetry](https://python-poetry.org/) для управления зависимостями
- [Ruff](https://docs.astral.sh/ruff/) для линтинга

## 🚀 Запуск проекта

1. Установите зависимости:

    make install

2. Запустите приложение

    make run
